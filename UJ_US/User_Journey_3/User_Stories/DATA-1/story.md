# DATA-1 — Discover and qualify providers

Journey: [UJ-BB-003](../../journey.md).
Client: [ICP-BB-003](../../../Ideal_Client_Profiles/ICP_3_Data_Operations/profile.md).

As a data steward, I want to give the agent a typed evidence need, so I can identify compatible sources without bespoke work for every supported feed.

Status: **Proposed autonomous onboarding; current connectors are developer-built**. This is not new customer validation.

## Acceptance

- Need specifies geography, work window, units, fields, freshness and allowed sources.
- Discovery records metadata, sample evidence and mapping reasons.
- Compatible, conditional, incompatible and unsupported sources are distinct.
- No provider API availability or access rights are assumed.

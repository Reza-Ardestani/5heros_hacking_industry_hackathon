# DATA-3 — Qualify costs and available resources

Journey: [UJ-BB-003](../../journey.md).
Client: [ICP-BB-003](../../../Ideal_Client_Profiles/ICP_3_Data_Operations/profile.md).

As a estimator or procurement contributor, I want to provide dated labor, material and equipment evidence, so I can supply a feasible envelope for each intervention.

Status: **Proposed; no resource API verified**. This is not new customer validation.

## Acceptance

- Rate, total cost and available quantity are separate fields with units and currency.
- Labor distinguishes roles, hours, shifts, skills and committed versus tentative capacity.
- Materials identify deliverable quantity/location/lead time; equipment identifies capacity and booking window.
- Quotes, indexes, assumptions and commitments are labeled separately.

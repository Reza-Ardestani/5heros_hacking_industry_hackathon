# DASH-5 — Save and share a review view

Journey: [UJ-BB-002](../../journey.md).
Client: [ICP-BB-002](../../../Ideal_Client_Profiles/ICP_2_Monitoring/profile.md).

As a engineering reviewer, I want to save a selected view with source versions and reporting period, so I can review the same evidence without recreating filters.

Status: **Proposed; not current dashboard functionality**. This is not new customer validation.

## Acceptance

- Saved view records filters, period, evidence versions and ownership.
- No private data is exposed through public share links by default.
- Comparison distinguishes changes in records from changes in selection.
